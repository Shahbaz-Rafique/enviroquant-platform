# EnviroQuant SaaS Workflow

# 1. Purpose

This document defines how users interact with the EnviroQuant platform.

The workflow focuses on:

- EIA creation
- EIA evaluation
- compliance review
- traceable findings
- structured environmental intelligence

---

# 2. User Types

## 2.1 Consultant
Creates and improves EIA documents.

Capabilities:
- create projects
- upload files
- build EIA sections
- receive AI guidance
- review compliance findings

---

## 2.2 Reviewer
Reviews EIA quality and compliance.

Capabilities:
- run evaluations
- inspect findings
- verify evidence
- review missing information
- generate review comments

---

## 2.3 Regulator (Future Phase)
Government or authority user.

Capabilities:
- compare EIAs
- benchmark quality
- monitor compliance trends
- audit decisions

---
